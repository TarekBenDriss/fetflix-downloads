# Fetflix Android TV downloads

[Download the latest Android TV APK](https://github.com/TarekBenDriss/fetflix-downloads/releases/latest/download/fetflix-tv.apk).

This public download contains the Fetflix app only. It does not include an IPTV provider or account. Enter your own Xtream provider details in the app, or configure a paired TV through the Fetflix admin panel.

The latest APK is built without Android debugging and uses the same signing certificate as the earlier Fetflix test APKs, so it can update those installs in place. The Google Play build uses a different app-signing certificate.

Source code is not published in this download repository; APKs are attached to releases.
